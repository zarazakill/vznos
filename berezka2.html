👥 Пользователи и права доступа

Список хранится в файле users.json в том же репозитории, что и остальные данные. Изменения нужно сохранить на GitHub кнопкой ниже — иначе они останутся только в этой вкладке браузера и пропадут при обновлении страницы.

🔑 GitHub-токен для сохранения

Нужен только для сохранения списка пользователей на GitHub (чтение данных участков токена не требует). Создайте fine-grained personal access token на github.com → Settings → Developer settings, с доступом только к репозиторию … и правом Contents: Read and write. Токен хранится только в этом браузере (localStorage) и никуда, кроме api.github.com, не отправляется.
